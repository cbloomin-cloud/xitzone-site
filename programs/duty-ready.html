How it works

The 8 weeks

Weeks 1-3

Build

Strength base, steady rucks, learn the circuit.

Weeks 4-6

Load

Heavier lifts, longer rucks, more rounds.

Week 7

Peak

For-time circuit.

Week 8

Deload + test

Easy week, then a 1.5-mile run or circuit test.

RPE is how hard a set feels from 1 to 10. RPE 7 means you could do about 3 more good reps; RPE 8 means about 2. RIR means reps in reserve, the same idea counted in reps. Pick loads by feel, not by a number someone else lifts.

Coach's notes

Make it work

  • This is general preparation, not your agency's fitness test. Check your department's standards.
  • Shift work: if you slept badly, drop one set from every exercise rather than skipping the day.
  • Build ruck weight slowly. Feet and back adapt more slowly than lungs.
