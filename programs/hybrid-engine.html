How it works

The 8 weeks

Weeks 1-3

Build

Aerobic base, clean technique on every station, steady strength.

Weeks 4-6

Develop

Longer threshold work and more compromised running: running on tired legs.

Week 7

Peak

Race simulation. Practice pacing and transitions.

Week 8

Deload + test

Less volume, stay sharp, then test.

RPE is how hard a set feels from 1 to 10. RPE 7 means you could do about 3 more good reps; RPE 8 means about 2. RIR means reps in reserve, the same idea counted in reps. Pick loads by feel, not by a number someone else lifts.

Coach's notes

Make it work

  • Running fitness drives hybrid racing. Never skip Day 2.
  • Scale sled loads so you keep moving; stopping costs more time than going lighter.
  • Keep at least one easy day between Day 1 and Day 4.
